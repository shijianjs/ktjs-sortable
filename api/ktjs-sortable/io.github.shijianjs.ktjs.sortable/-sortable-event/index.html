SortableEvent

external interface SortableEvent

The event object the callbacks receive.

Upstream sets the fields per event, so most are optional: onStart has no oldIndex, an onAdd between two lists has both from and to. Event in kotlin-browser is a class, and an external interface cannot extend one, so the fields are declared here instead of inheriting them.
