SortableOptions

external interface SortableOptions

The options object upstream reads, plus the callbacks it fires.

Every field is nullable and starts out undefined, which is what lets upstream's defaults apply. Build one with sortableOptions. The package ships no .d.ts; these declarations were written from src/Sortable.js and cross-checked against @types/sortablejs 1.15.9 — see the coverage document.
