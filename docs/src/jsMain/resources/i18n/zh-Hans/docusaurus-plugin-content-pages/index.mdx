<ktjs-features section-title="封装了什么" tinted>

<ktjs-feature icon="lucide:hand" title="Sortable 类">`createSortable`、`toArray`、`sort`、`option`、`destroy`——每个实例成员都按 `src/Sortable.js` 声明，没有 dynamic 调用。</ktjs-feature>

<ktjs-feature icon="lucide:list" title="选项即构造器">`sortableOptions { }` 只写你设过的字段，其余保持 `undefined`，上游默认值原样生效。</ktjs-feature>

<ktjs-feature icon="lucide:radio" title="十一个带类型的回调">`onStart` → `onMove` → `onSort` → `onEnd`，每个都收到一个 `SortableEvent`；`onMove` 可以返回 `false` 否决落点。</ktjs-feature>

<ktjs-feature icon="lucide:users" title="带规则的分组">对象形式用 `sortableGroup("board") { pull = …; put = … }`，而纯字符串最终也归一化成同一个形状。</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="对真实库测试">模块的浏览器测试对着打包进来的 `sortablejs` 建真列表；demo 另有 Playwright 套件，会把顺序读回来比对。</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="双语文档">本站由 ktjs-docusaurus 构建：类型化配置、Markdown 页面、中英两版。</ktjs-feature>

</ktjs-features>
