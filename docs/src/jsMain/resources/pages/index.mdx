<ktjs-features section-title="What it wraps" tinted>

<ktjs-feature icon="lucide:hand" title="The Sortable class">`createSortable`, `toArray`, `sort`, `option` and `destroy` — every instance member declared from `src/Sortable.js`, no dynamic calls.</ktjs-feature>

<ktjs-feature icon="lucide:list" title="Options as a builder">`sortableOptions { }` writes only the fields you set; every other field stays `undefined`, so upstream's defaults apply untouched.</ktjs-feature>

<ktjs-feature icon="lucide:radio" title="Eleven typed callbacks">`onStart` → `onMove` → `onSort` → `onEnd`, each with one `SortableEvent`; `onMove` may return `false` to veto a drop.</ktjs-feature>

<ktjs-feature icon="lucide:users" title="Groups with rules">`sortableGroup("board") { pull = …; put = … }` for the object form, while a plain string still normalises to the same shape.</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="Tested against the real library">The module's browser tests build real lists against the bundled `sortablejs`; the demo has its own Playwright suite that reads the order back.</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="Docs in two languages">This site is a Kotlin/JS module built by ktjs-docusaurus: typed configuration, Markdown pages, English and Chinese.</ktjs-feature>

</ktjs-features>
